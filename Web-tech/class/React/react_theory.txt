***React**

React : react is js library developed by meta to build a fast and interactive user interfaces
---It is single page application(SPA)-page does not reload only contain change
    ex, instagram, facebook

why do we use react?
problem with tradition js : fully page reload, complex DOM manipulation, hard to manage large application.
by using react : Updates only required part, use reusable components.


**Virtual DOM**
--react creates a copy of real DOM means virtual DOM.
--when data changes reat updated virtual DOM.
--Updated only change the part in real DOM.
--It is used for high performance.
